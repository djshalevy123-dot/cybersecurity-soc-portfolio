# Public Publication Checklist

Complete this checklist before adding a report, screenshot, configuration, or evidence file to the public repository.

- [ ] Remove passwords, tokens, API keys, recovery codes, and private keys.
- [ ] Remove personal email addresses, phone numbers, and home or workplace details.
- [ ] Review usernames, hostnames, IP addresses, domains, and file paths; retain only lab-safe values.
- [ ] Remove browser tabs, notifications, account names, and unrelated desktop content from screenshots.
- [ ] Confirm that every target system was part of the authorized lab.
- [ ] Verify that commands do not expose active credentials or reusable secrets.
- [ ] Export only the final report pages and screenshots needed to support the finding.
- [ ] Confirm that links work from a clean browser session.
- [ ] Review spelling, dates, metrics, severity, and incident classification.
- [ ] Keep the ethical-use statement in the repository.
