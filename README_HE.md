# תיק עבודות סייבר ו־SOC — שליו יהושע

זהו מדריך עברי משלים לתיק העבודות הציבורי. עמוד ה־README הראשי נכתב באנגלית כדי להתאים למגייסים ולמראיינים, והדוחות המלאים נשמרו גם באנגלית וגם בעברית לצורכי למידה וחזרה.

## חמשת הפרויקטים

1. **הנדסת זיהוי ב־SIEM** — קליטת לוגים מ־Windows ומ־Sysmon ל־Splunk ויצירת התראה ל־PowerShell ExecutionPolicy Bypass.
2. **ניהול טיקטים ואירועים** — חקירת INC-2026-001, תיעוד ראיות, עמידה ב־SLA וסגירה כ־True Positive מורשה.
3. **ניתוח תעבורת רשת** — ניתוח PCAP ב־Wireshark, זיהוי סריקת פורטים 135, 139 ו־445 ושלילת פעילות המשך.
4. **אבטחת שרת Web בלינוקס** — הקמת Apache על Ubuntu, בדיקות נגישות והקשחה עם אימות חוזר.
5. **IAM ובקרת גישה** — משתמשים, קבוצות, ACL, sudo מוגבל, מדיניות סיסמאות ותהליך נעילה והסרה.

## איך להציג את התיק בראיון

- לפתוח את מסמך הסקירה באנגלית ולהציג תחילה את חמשת הפרויקטים.
- לבחור את INC-2026-001 כמקרה המרכזי ולהסביר את תהליך הזיהוי, החקירה וההחלטה.
- להציג דוח מלא או צילום מסך רק אם המראיין מבקש להעמיק.
- לשמור עותק מקומי של התיק למקרה שאין חיבור לאינטרנט.

כל הפעילויות בוצעו במעבדה מבודדת ומורשית בלבד.
